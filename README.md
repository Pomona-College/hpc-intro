# Introduction to HPC Systems

Pomona College HPC Workshop Series

## Overview

This workshop introduces the fundamental concepts of high-performance computing (HPC) and provides hands-on experience accessing Sagehen, Pomona College's research computing cluster. Learners will understand cluster architecture, connect securely via SSH, navigate the filesystem, and submit their first computational job.

## Episodes

1. **What is HPC?**: Define high-performance computing, understand cluster components, and learn why HPC matters for research
2. **Connecting to Sagehen**: Set up SSH access and use OnDemand web portal for secure cluster connection
3. **Navigating the Filesystem**: Explore cluster directories, understand storage organization, and manage research data
4. **Cluster Architecture**: Learn about head nodes, compute nodes, and different hardware resources available
5. **Software Modules**: Discover how to load and use software packages on the cluster
6. **Running Your First Job**: Submit an interactive job and observe computation in action

## Prerequisites

- Basic computer literacy and ability to use a terminal
- Pomona College account credentials
- DUO multi-factor authentication enabled

## Learning Objectives

After completing this workshop, learners will be able to:
- Define high-performance computing and understand its role in modern research
- Distinguish between personal computers and HPC clusters
- Connect securely to Sagehen using SSH or OnDemand
- Navigate the cluster filesystem and organize research data
- Load and use software modules
- Submit and monitor interactive jobs

## Target Audience

Researchers new to HPC, including undergraduate students, graduate students, and faculty members beginning computational work at Pomona College.

## Duration

Approximately 2.5 to 3 hours including hands-on exercises.

## Technical Requirements

- Sagehen HPC cluster account
- SSH client (built-in on macOS and Linux, PuTTY or Windows 10+ OpenSSH on Windows)
- Web browser (for OnDemand portal)
- Internet connection
