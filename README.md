# Introduction to HPC Systems

Pomona College HPC Workshop Series

## Overview

This workshop introduces the fundamental concepts of high-performance computing (HPC) and provides hands-on experience accessing Sagehen HPC, Pomona College's research computing cluster. Learners will understand cluster architecture, connect securely via SSH, navigate the filesystem, and submit their first computational job.

## Episodes

1. **What is HPC?**: Define high-performance computing, understand cluster components, and learn why HPC matters for research
2. **Why Use HPC?**: Recognize when an HPC cluster is the right tool and survey Sagehen's hardware and storage
3. **Connecting to Sagehen**: Set up SSH access, DUO authentication, and the OnDemand web portal
4. **Navigating the Filesystem**: Explore cluster directories, understand storage organization, and check quotas
5. **Files and Directories**: Create and manage files, organize research work, and set permissions
6. **Cluster Architecture**: Learn about partitions and Sagehen's hardware specifications
7. **Nodes and Partitions**: Match jobs to the right partition and understand SLURM resource allocation
8. **Software Modules**: Discover how to load and use software packages with Lmod
9. **Running Your First Job**: Write, submit, and monitor a SLURM batch job
10. **Next Steps**: Interactive jobs, email notifications, and the rest of the workshop series

## Prerequisites

- Basic computer literacy and ability to use a terminal
- Pomona College account credentials
- DUO multi-factor authentication enabled

## Learning Objectives

After completing this workshop, learners will be able to:
- Define high-performance computing and understand its role in modern research
- Distinguish between personal computers and HPC clusters
- Connect securely to Sagehen using SSH or OnDemand
- Navigate the cluster filesystem and organize research data
- Load and use software modules
- Submit and monitor interactive jobs

## Target Audience

Researchers new to HPC, including undergraduate students, graduate students, and faculty members beginning computational work at Pomona College.

## Duration

Approximately 3.5 to 4 hours including hands-on exercises (a 2 to 2.5 hour abbreviated version is described in the instructor notes).

## Technical Requirements

- Sagehen HPC cluster account
- SSH client (built-in on macOS and Linux, PuTTY or Windows 10+ OpenSSH on Windows)
- Web browser (for OnDemand portal)
- Internet connection
